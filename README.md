
# Cisco Networking Labs | Network Configuration & Troubleshooting

## Project Overview

This repository documents hands-on networking labs completed using Cisco Packet Tracer.

The labs focus on IPv4 addressing, LAN connectivity, multi-router network topologies, and network connectivity testing using ICMP.

The documentation includes screenshots of network topologies, addressing configurations, ping results, and packet simulation observations.

## Technologies & Skills

- Cisco Packet Tracer
- IPv4 Addressing
- Local Area Networks (LANs)
- Routers and Switches
- Network Topology Design
- ICMP and Ping Testing
- Network Connectivity Troubleshooting
- Packet Simulation and Analysis

## Lab 1: LAN Configuration & IPv4 Addressing

### Objective
Examine network connectivity between end devices connected through routers and switches.

### Activities
- Worked with LAN topologies in Cisco Packet Tracer.
- Examined IPv4 addressing across network devices.
- Identified router, switch, and PC connections.
- Tested network connectivity using ping.

### Evidence
Screenshots of the LAN topology, addressing information, and connectivity tests.

## Lab 2: Multi-Router Network Topology

### Objective
Examine connectivity across a network topology containing multiple routers and LAN segments.

### Activities
- Worked with a topology containing three routers.
- Examined connections between routers and LANs.
- Reviewed IPv4 addressing across network segments.
- Used packet simulation to observe network communication.

### Evidence
Screenshots of the three-router topology and packet simulation results.

## Lab 3: ICMP Connectivity & Troubleshooting

### Objective
Test network reachability and observe ICMP communication.

### Activities
- Executed ping tests to verify connectivity.
- Observed successful ICMP communication.
- Reviewed unsuccessful packet simulation results.
- Used Cisco Packet Tracer simulation mode to examine packet delivery.

### Results
A documented ping test returned four successful replies, demonstrating connectivity to the tested destination.

Other simulations showed both successful and unsuccessful ICMP results, providing opportunities to examine network behavior.
